Las herramientas: MPLAB y VirtualBreadBoard

HerramientaPara quéLo que hay que saber usar
MPLAB IDEEditar, ensamblar y simular.Crear el proyecto, seleccionar el PIC16F84A, ensamblar y ejecutar paso a paso.
Simulador MPLAB SIMEjecutar sin hardware.Puntos de ruptura, ejecución paso a paso y ventana de Watch para ver registros.
StopwatchMedir tiempos.Da el número exacto de ciclos entre dos puntos: es la forma de comprobar una rutina de retardo.
StimulusSimular entradas.Forzar niveles en las patillas para probar pulsadores sin montar nada.
VirtualBreadBoardSimular el circuito completo.Montar LED, displays, pulsadores y motores alrededor del PIC y ver el comportamiento.

El flujo de trabajo que ahorra más tiempo: escribir el código, ensamblar, simular en MPLAB comprobando registros y ciclos, y sólo entonces pasar a VirtualBreadBoard o al hardware real. Depurar en la placa lo que se puede depurar en el simulador es perder la tarde.

Errores que delatan un problema concreto

SíntomaCausa casi segura
No se enciende nada en las salidasFalta el cambio de banco antes de escribir en TRIS, o se olvidó volver al banco 0.
El programa se reinicia solo cada pocoPerro guardián activado en la palabra __config.
El micro parece muerto al usar interrupcionesNo se borra el bit F en la rutina: se vuelve a entrar sin parar.
Fallos aleatorios con interrupcionesNo se salvan W y STATUS.
Una pulsación cuenta muchas vecesFalta antirrebote.
El display muestra dígitos fantasmaNo se apagan los dígitos antes de cambiar el patrón.
Los segmentos encendidos son los que deberían estar apagadosTabla de cátodo en un display de ánodo común.
El bucle de espera del TMR0 sale inmediatamenteNo se borró T0IF antes de esperar.
La escritura en EEPROM no ocurreSecuencia 0x55/0xAA alterada, o falta WREN.
Un salto de tabla va a parar a cualquier sitioLa tabla cruza el límite de 256 palabras.

Plantilla de programa para el examen

Esta plantilla vale para casi cualquier ejercicio y ya puntúa por sí sola. Escríbela primero y después rellena:

list P=16F84A #include <p16f84a.inc> __config _XT_OSC & _WDT_OFF & _PWRTE_ON ; ---- variables (siempre a partir de 0x0C) W_TMP equ 0x0C S_TMP equ 0x0D VAR equ 0x0E VAR1 equ 0x0F org 0x00 ; vector de reset goto Inicio org 0x04 ; vector de interrupción movwf W_TMP swapf STATUS,0 movwf S_TMP ; ... identificar fuente, atender, BORRAR EL BIT F ... swapf S_TMP,0 movwf STATUS swapf W_TMP,1 swapf W_TMP,0 retfie Inicio bsf STATUS,RP0 ; ---- BANCO 1 movlw b'00000000' movwf TRISB ; 0 = salida, 1 = entrada movlw b'00011111' movwf TRISA movlw b'00000111' ; OPTION: TMR0 interno, DF 1:256 movwf OPTION_REG bcf STATUS,RP0 ; ---- BANCO 0 clrf PORTB ; inicializar salidas Bucle ; ---- programa principal goto Bucle ; ---- subrutinas Delay50 movlw d'200' movwf VAR1 Atras1 movlw d'82' movwf VAR Atras decfsz VAR,1 goto Atras decfsz VAR1,1 goto Atras1 return end
